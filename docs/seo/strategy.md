## 記事執筆ガイドライン

1. **1記事1キーワード**。上の台帳から未着手（[ ]）のものを優先度順に1つ選び、着手したら `[x]` にしてslugと日付を記す
2. **カニバリ回避**: 執筆前に `src/data/news/` の既存記事タイトルを確認し、同じ検索意図の記事があればキーワードを変える
3. 文字数 **2,500〜4,000字**。H2/H3で構造化。結論ファースト
4. **一次情報を必ず入れる**: ZetaXの研修現場の知見（各回20名制、現場ヒアリング設計、製造業70名/商社50名の事例、研修+要件定義セット等）を1セクション以上。一般論だけの記事は書かない
5. **事実の捏造禁止**: 統計・制度（助成金等）・他社情報を書く場合は、確認できた出典URLを本文に明記。確認できなければ書かない
6. frontmatter は `src/content.config.ts` の news スキーマに従う:
   - `category: 技術コラム`
   - `description` は120〜155字（max 160）で検索意図に応える
   - `faq` を3〜5問（FAQPageリッチリザルト対象）
   - `author: ZetaX AI研修チーム` / `authorRole: 現役AI開発エンジニア`
   - `heroImage: ./heroImage.png`（`docs/seo/hero-templates/hero-{1..6}.png` から1枚コピー。直近記事と違う番号を使う）
7. **内部リンク**: 本文中に `/ai-training/`（サービス紹介として自然に）、記事末尾に資料請求CTA（`/ai-training/#request`）を必ず入れる。関連する過去記事にも1〜2本リンク
8. slugは英語ケバブケース（例: `ai-training-cost-guide`）
9. 公開前に `npm install && npm run build` が通ることを確認
